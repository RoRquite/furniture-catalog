# Telegram Setup — открытие каталога внутри Telegram

Пошаговый чеклист. Токен бота **нигде не нужен проекту** — все действия с
BotFather выполняются вручную в Telegram, токен остаётся только у вас.

## 1. Собрать проект

```bash
cd furniture_catalog
npm run build
```

Без URL: сборка пройдёт и напомнит про Menu Button.
С URL сразу:

```bash
MINI_APP_URL="https://ВАШ_АДРЕС/путь/" npm run build
```

URL обязан начинаться с `https://` — иначе сборка завершится ошибкой.

## 2. Где результат

Всё для публикации — в каталоге **`dist/`** (index.html, js/, css/, data/,
images/). Публикуется содержимое папки целиком.

## 3. Разместить по HTTPS

Telegram требует публичный HTTPS. Подойдёт любой статик-хостинг
(GitHub Pages / Netlify / Cloudflare Pages / собственный nginx+TLS).
Загрузите содержимое `dist/` как есть. HTTP для production использовать нельзя.

## 4. Какой URL нужен Telegram

Прямой адрес вашего `index.html`, например:
`https://username.github.io/furniture-catalog/`
Этот же адрес передайте при сборке через `MINI_APP_URL`.

## 5. Настройки BotFather (выполняется вручную)

1. Откройте @BotFather → `/mybots` → выберите бота.
2. **Bot Settings → Menu Button → Configure menu button** →
   отправьте ваш HTTPS URL → задайте название кнопки (например «Каталог»).
3. Альтернатива: `/newapp` (если нужен отдельный апп-линк).
4. Токен бота вводите только в диалоге с BotFather — проекту он не нужен.

## 6. Открыть Mini App

Откройте чат с вашим ботом → нажмите кнопку меню «Каталог» →
приложение откроется внутри Telegram.

## 7. Проверить BackButton

- Зайдите в категорию → системная стрелка «назад» внизу экрана Telegram
  должна работать;
- из карточки товара она возвращает именно в категорию.

## 8. Проверить категории

На главном экране нажмите каждую из 3 категорий — список товаров открывается.

## 9. Проверить карточку товара

Нажмите товар: изображение, описание, цена, характеристики на месте.

## 10. Проверить Favorites

«♡ В избранное» → метка меняется на «✓ В избранном»; экран избранного
показывает товар; повторное нажатие убирает; после перезапуска аппа список
сохраняется (localStorage).

## 11. Проверить Order

«Заказать»: текст заказа копируется и открывается чат контакта
(`data/config.json → order.contactUrl`; до замены placeholder показывается
только текст).
